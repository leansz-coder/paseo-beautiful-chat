# Changelog

## 0.2.0

First public Git release of this community fork.

- Group mounted recent tool, reasoning and image-result rows on desktop/web, with running, failure and cancellation counts.
- Preserve styled, individually expandable cards inside groups.
- Load supported image-only results on demand and add image zoom controls.
- Refine prompt colors, metadata hierarchy, glass effects and the running indicator.
- Reduce repeated animation, pointer, highlighting and usage work; paginate long code blocks.
- Include 42 regression tests, Git dependency preparation and third-party asset notices.

Known limits: tested on Paseo 0.11.1 macOS desktop; DOM features depend on host markup. Native mobile and virtualized old history use individual cards. This is an experimental release, not a marketplace-reviewed artifact.
